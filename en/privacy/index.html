DoseShift: Pill Reminder App

Privacy Notice

This page explains in plain language what data DoseShift, its website, and its feedback form handle.

Last updated: 14 September 2026.

What This Notice Covers

It covers the DoseShift Android app, the public DoseShift website, APK downloads, update checks, and the feedback form. The app is a reminder tool, not medical advice.

Data in the App

To run reminders, the app stores on your phone:

  • the medication name, interval, first planned time, daily limit, and notes;
  • the plan state and a local history of taken, postponed, skipped, and scheduled reminders;
  • app settings, including language and reminder sound.

The core function does not require an account, cloud sync, or sending this data to the developer. Medication data and dose marks are not attached to update checks, counters, or feedback.

The data is kept in the app's local storage. The current build permits Android's standard backup, so a copy of local data may be handled under Android/Google rules when backup is enabled on the device or account. To remove data from a phone, uninstall the app and, if needed, remove its backup in Android or account settings.

Technical Data and Counters

When an APK or update is downloaded, the service receives a download or update event. To avoid counting repeat events, the app creates a random installation identifier, and the website creates or uses a random identifier in the doseshift_analytics cookie. It is not created from a name, telephone number, advertising ID, location, medication name, or dose history.

The website cookie lasts for up to one year. The private counter store keeps only the event type and a one-way hash of the random identifier; the public page shows only aggregate download and update totals.

As with most websites, infrastructure providers may process technical request data such as an IP address, date and time, browser, and security logs. The public site is hosted by GitHub Pages. Download, update, counter, and feedback services use Yandex Cloud infrastructure.

Feedback

If you voluntarily submit the form, we store the situation you describe, your idea or suggestion, an optional app version, and an optional reply contact. Please do not submit diagnoses, prescriptions, health information, payment-card details, passwords, or other sensitive information.

The message and contact are kept in the developer's private storage, not on the public website. They are used only to review the request and, if you leave a contact, reply to it or tell you about a related fix. We do not use the contact for bulk marketing. The current release has no automated retention period for reports; until one is introduced, a report remains in private storage. To request access, correction, or deletion, submit a new feedback message and include the receipt number of the report.

Who May Process Data

  • DoseShift developer — receives only voluntarily submitted feedback and contact information, if supplied.
  • GitHub Pages — hosts the public static pages and maintains infrastructure logs.
  • Yandex Cloud — provides the download, update-check, counter, and private feedback-storage services.
  • Android and Google — the operating system handles notifications and, if enabled on the device, backups under its settings and policies.

We do not sell data or send medication data from the app to advertising networks.

Security and Your Choices

Communication between the app, website, and service uses HTTPS. Access to feedback is restricted through private storage. No transmission or storage method is absolutely secure, so please do not submit sensitive information through the form.

You can choose not to use the feedback form, uninstall the app and remove local data, clear the website cookie in your browser, or block cookies in browser settings. For data questions, use the feedback form.

Changes

If data handling changes, we will update this page and its date at the top. Material changes will be reflected before they take effect where required by law.
